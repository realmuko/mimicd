拟真控制终端 · 目标分层（v0 提案）
控制流自上而下，每一层都能单独替换；模型只出「意图」，坐标与手势由代码保证。

①意图层 · DeepSeek 主模型

只输出 Intent：open_chat · reply(text) · send_sticker · read · wait · escalate。
不出像素坐标、不拼 shell 串、不关心输入法怎么切。

②节奏层 · Presence & Rhythm

「她此刻在不在、要不要现在做」：在线时段门控 · 阅读停顿 · 回复延迟采样（双对数正态）· 会话与休息节奏。
模型 20–40 s 的思考时间，被这一层吸收成「像人」。

③编排层 · Orchestrator

Intent → 动作计划：预算 / 幂等键 / pre 前置断言 / 三重熔断 / 用户一碰手机就让位。
不可逆动作强制 dry-run + 确认，失败不补偿、升级给人。

④拟真层 · Humanizer（新增，当前架构里没有这一层）

把「点发送」变成一次人类手势：tap 时长 40–180 ms · 落点框内高斯 · 滑动加速-峰值-减速曲线 ·
逐字击键时间线（含错字、发现停顿、退格、补打）。

⑤执行层 · Actuator

唯一能改设备状态的地方：uinput / ADBKeyboard(base64) / adb tap 三条适配器；
单写者串行队列，每个动作带 pre 断言与按类型分档的 settle_ms。

⑥设备 · 真机微信 1080×2160

USB + ADB，Android 10。「像不像人」最终都要在这一台机器上落地。

⑦感知层 · Perception

a11y dump（有就用）· 截图 + 区域 OCR（微信主战场）· 像素探针（30 ms 判页面）· 帧差/帧计数判稳。
每份观察都带耗时与置信度；低置信时选择「不动」。

⑧世界模型 · World State

每个会话：类型（群 / 私聊 / unknown）· 未读 · 讨论串 · 冷却 · 最近发言；再加焦点 App、Activity、IME、屏幕状态。
unknown 时只做低风险动作（进去看一眼，不主动开口）。

事件总线 · EventStore

append-only JSONL，唯一的协调源。

ObservedDecided
PlannedExecuted
Verified

只存图片路径 + 哈希 + 尺寸，不存 base64；事件带 schema 版本，只增不删。

回放 & 评测 · Replay

离线重放每一次观察与决策；改参数前后直接 diff，而不是「感觉好点了」。
回放/重试模式强制 dry-run：永不再发一条消息。

拟真度量 · Realism Audit

L1 事件级：动作时序 vs 自采真人分布（KS 检验）
L2 会话级：人盲猜 + 简单分类器判别
L3 任务级：成功率 / 耗时（拟真不能牺牲功能）

记忆 · 人格 · 关系

fish-memory：跟谁聊过什么、说话风格、谁可以开玩笑。
这一层不是「拟真」，是「像她」。

安全边界

屏幕内容 = 不可信数据，不是指令；
不可逆动作前先持久化，再请示。

三层拟真预算：L0 能跑（现状）→ L1 不露馅（通道 + 形态 + 节奏，性价比最高）→ L2 骗过判别（真人轨迹库、个性化，成本陡增，建议只做局部）
