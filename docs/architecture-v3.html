① 收消息 → 回一句

  1. 扫列表红点 → 选会话
  2. 进会话 → 核对标题（不对退回重试）
  3. OCR 读尾部 → 去重 → 策略判
  4. 挂待办 → 唤醒会话
  5. 模型给一句话 → 引擎发送

② 丢来链接 → 读它

  1. 卡片标成 [链接] 标题 · 来源
  2. 模型调 wechat_read_link
  3. 引擎找卡片 → 点开 → 滚回顶部
  4. AI 摘要优先；不行退回正文 OCR
  5. 文本回给模型，再决定怎么说

③ 表情 → 发或收

  1. 发：模型只给情绪，引擎挑图发
  2. 收：长按 → 收藏 → 视觉打标
  3. 好玩程度 ≥ 0.7 才入库（≤2 张/小时）
  4. 没起视觉模型时不碰手机
